The discovery repair improves usability while the measured cold prescribed workflow still loses to Grep on latency/input.

Combined-candidate validation also caught and repaired native Unix URI restoration in persisted snapshots, an integration test expecting the pre-compact response shape, and selected-file errors being hidden by unrelated files reaching the global diagnostic limit. Native CI and the disposable SQL Server job verify the first two; deterministic scope-before-limit regression tests cover the last. Failed CI attempts remain retained as evidence, not successful checks.

The [first combined result](../evaluation/results/sql-server-samples-combined-first-20261017.md) had zero wire overflows but 14 invalid mixed-selector requests. A matching module identity can now accompany report pages while conflicting/stale identities remain rejected. The [final clean result](../evaluation/results/sql-server-samples-final-clean-20261017.md) has zero tool errors/overflows, but mean time/input are 31.6 s/46.4k versus Grep 17.0 s/21.4k. Factual scores are 94.1% versus 92.9%, citations 97.9% versus 100%, strict passes 10 versus 8; implementing-agent review remains subjective. Structural resource/quality targets are not met. The earlier [availability cohort](../evaluation/results/sql-server-samples-available-first-20261017.md) made no MCP calls and missed the simple-control overhead target. Earlier docs-inclusive artifacts retain an exposure-risk qualification; the final archive excludes maintainer gold. This is repair/usability work, not demonstrated Grep superiority.

All 329 Windows C# tests pass (18 environment skips), as do 332 Unix tests (15 skips), 32 Python cases (one Windows symlink skip) and 43 disposable SQL Server tests without skips. [Native CI](https://github.com/yongding422/ClaudeCode_SQL_LSP/actions/runs/39070924405) and [backend measurements](../evidence/benchmark-final-native-reuse-20261017.json) retain artifact/source identity. The original baseline and every earlier experiment remain unchanged. Use Grep/Read for short known-source tasks; broader end-to-end model benefits are not established by backend reuse alone.

[Actual candidate marketplace installation](https://github.com/yongding422/ClaudeCode_SQL_LSP/actions/runs/39072798294) passed on Windows, Linux, Apple Silicon and Intel Mac using the published exact archives.
