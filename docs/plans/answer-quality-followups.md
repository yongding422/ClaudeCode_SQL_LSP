# Follow-ups from the first-response benchmark

Checkpoint `ba76e20` on main preserves the first-response implementation, evaluation workflow and all 2026-10-18 studies. Follow-up fixes are developed in order on `codex/benchmark-accuracy-followups`; source publication does not update marketplace archives.

1. **Actionable scope recovery (implemented; model benefit unmeasured).** Discovery offers `scopeChoice.directory`/`directoryUri` and a ready-to-use `scopeChoice.moduleRef` for ambiguous SQL-only copies. It offers the broadest physical directory that separates that declaration, not inferred SQL project/database membership. The caller explicitly chooses based on requested source. Unscoped handles, same-file duplicates and verified-project duplicates remain ambiguous; outside dependencies stay unresolved. All 28 scope/selector/brief/paging protocol tests passed, including live and materialized indexes, stale handles and conflicting boundaries.
2. **Source-based transaction/data-flow evidence (implemented; model benefit unmeasured).** Added transaction syntax contracts, declared native/execution options, local table transfers/reads, unevaluated EXEC-string construction and brief source-order/region citations. [Contract and limits](../execution-evidence.md). Locked restore, Release build and format verification passed. The full local suite passed: 173 Core, 101 MCP, 60 LSP and 29 provider tests, with 18 environment-dependent skips. Full sequential CFG, runtime outcomes and complete column lineage remain unsupported.
3. **Reduce repeated context (implemented; model benefit unmeasured).** Expansion responses inherit the original report's coverage/context/scope through `contextRef`, retaining page generation, evidence, omissions and timings. Materialized expansion verifies current bytes without loading rich bodies again. New protocol cases cover rich-body eviction, citations and same-size/time edits; 24 targeted MCP tests pass. Instrumentation counts complete payload/text/brief bytes and cited brief delivery separately from accuracy; the Python suite passes (55 passed, one host symlink skip). Historical result files are unchanged. [Contract](../first-response-evidence.md).
4. **Stronger validation (cohort/protocol implemented; fresh model and developer review pending).** Preserved all historical cohorts/grades. Added [three new primary procedures and matching source-backed acceptance expectations](../evaluation/new-procedures-protocol.md), checked against earlier evidence lists, with a separate pre-run protocol and unchanged acceptance rules. No model sessions have run for this cohort. Independent developer acceptance and measured correction effort require actual developer feedback and cannot be generated by the plugin or implementing agent.

The latest comparison remains [2/10 plugin answers versus 0/10 Grep accepted](../evaluation/results/sql-server-samples-first-response-20261018.md), with greater plugin time/input usage. Passing deterministic tests or fewer bytes does not demonstrate better model-answer acceptance or token savings. General M6 editor work remains deferred.
