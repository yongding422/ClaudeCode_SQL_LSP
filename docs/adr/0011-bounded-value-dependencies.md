# ADR 0011: bounded source definitions and EXEC bindings

Date: 2026-10-14. Implement the first bounded slice of increment 4, using ScriptDOM 180.117.0 and existing semantic scope/resolution. General IDE work stays deferred. No new package dependency, hook, SQL execution API or telemetry collector is added.

Compiled probes verified ProcedureParameter defaults/modifiers, EXEC arguments/return variable, SET/SELECT assignment fields and WHERE/HAVING/JOIN expressions. `SqlValueFlow` retains variable/declaration identities and revision-local definition facts. Simple sequential assignments replace prior sources; IF merges alternatives. Loops, CATCH, unstructured jumps, SELECT row/evaluation order, opaque writes and call outputs cannot be treated as a last-known value. Source completeness is explicitly distinct from knowing a runtime value. Complex expressions remain observations without evaluation.

`SqlValueCalls` resolves an EXEC through the existing selected-source resolver and reads the original AST signature. Display documentation and hidden metadata do not become synthetic formals. Validate the whole named/positional/default/OUTPUT argument list before publishing bindings. Capture every input before copy-back, preserve aliased output uncertainty, and keep caller return status separate from arbitrary callee RETURN expressions. Binding records carry exact formal anchors, target module ID and source revision, including when expansion stops before the callee body.

Callee entry inputs remain symbolic: two callers do not overwrite a shared callee's state. A client can follow formal identities into callee filter/assignment observations, with possible sources and limitations intact. This is not interprocedural constant propagation, correlated path solving, SQL type checking or column lineage. Parameter defaults are separate observations and apply only when selected by verified call syntax.

Value records/bindings consume the existing shared fact budgets, capped at 512 items per module, with separate variable/fact/call/argument/input/source limits. Previews retain full source ranges and safe UTF-16 truncation. Tests cover false propagation and invented bindings as well as positive examples through core, independent MCP and selected catalog/hybrid sources. Six public tasks include authored, source-reviewed gold assertions; independent benchmark review remains outstanding.
